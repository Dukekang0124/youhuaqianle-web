装到手机上（四步）

  1. 点上面那颗按钮，安装包会存到手机的「下载」里。它是 arm64 架构的 release 包，近两年的手机基本都是这个架构。
  2. 第一次从浏览器装包，系统会问「是否允许安装未知来源应用」——只在「设置 → 应用 → 允许安装未知应用」里对这一次放行就行，装完可以关掉。
  3. 点开下载好的 apk，按提示安装。装完打开，账本从空开始；之前在网页版记过账的，用「我的 → 导入备份」把导出的 JSON 灌进来就接上了。
  4. 以后更新在 App 内完成：设置 → 关于与更新。它读的清单就是这一页读的同一份 updates/version.json。

安装时如果提示「已损坏」或「解析软件包时出现问题」，先对照上面那两个校验值——字节数或 MD5 对不上，说明这一份在下载路上断了，重新下载即可，不是包本身坏了。

这一个包的分块清单

同一个安装包切成几块放在 updates/parts/ 下，每一块单独记了长度与 SHA-256。App 检测到这份清单就会走分块下载：一次大失败被切成几次小失败，坏哪块补哪块，最多重取一块而不是整包重下。

—

块地址是清单里的相对路径，按「updates/ 这个目录 + 清单写的地址」解析——换托管不用重算哈希。逐块校验全部通过才允许整包拼回；任何一块长度或 SHA-256 与磁盘不符，发布脚本直接失败，宁可不发这份清单。
